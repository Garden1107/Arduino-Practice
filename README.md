# Arduino-Practice

Arduino practice projects and experiments while learning embedded systems.

아두이노를 학습하며 진행한 실습 및 간단한 프로젝트를 정리한 저장소입니다.

## Contents / 구성

* LED brightness control and PWM
  LED 밝기 조절 및 PWM
* RGB LED color control
  RGB LED 색상 제어
* Piezo buzzer and melody playback
  피에조 부저 및 음계 재생
* IR remote control
  적외선 리모컨 수신 및 제어
* DHT11 temperature and humidity sensing
  DHT11 온습도 센서 활용
* I2C LCD display
  I2C LCD 출력
* Servo motor control
  서보모터 제어
* Sensor and input-based control experiments
  센서 및 입력 장치를 활용한 간단한 제어 실습

## Purpose / 목적

This repository contains Arduino practice projects created while learning the basics of sensors, input/output, communication, and embedded systems.

센서, 입출력, 통신 및 임베디드 시스템의 기본적인 동작 원리를 학습하며 진행한 아두이노 실습 및 간단한 프로젝트를 정리하는 것을 목적으로 합니다.

## Notes / 참고사항

Some projects were created by following tutorials, while others were modified or extended as part of my own practice and experimentation.

일부 실습은 강의 및 튜토리얼을 따라 구현하였으며, 학습 과정에서 코드를 직접 수정하거나 기능을 추가하여 응용한 경우도 있습니다.
