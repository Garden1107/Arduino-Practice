# Arduino-Practice
Arduino practice projects and experiments while learning embedded systems.




Arduino를 학습하며 진행한 실습 및 간단한 프로젝트를 정리한 저장소입니다.

## Contents

- LED 밝기 조절 및 PWM
- RGB LED 색상 제어
- 피에조 부저 및 음계 재생
- 적외선 리모컨 수신
- DHT11 온습도 센서
- I2C LCD 출력
- 센서와 입력 장치를 활용한 간단한 제어 실습

## Purpose

Arduino를 직접 다루면서 센서, 입력/출력, 통신 및
기본적인 임베디드 시스템의 동작 원리를 학습하는 것을 목적으로 합니다.

## Notes

일부 실습은 강의 및 튜토리얼을 참고하여 구현했으며,
학습 과정에서 코드를 수정하거나 기능을 추가한 경우가 있습니다.
